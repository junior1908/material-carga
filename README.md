# CONFERÊNCIA DE MATERIAL CARGA
## Site para conferência de material carga, a partir de 2026.

**Motivo:** Anualmente (ou a cada semestre, conforme legislação), cada setor tem que realizar a conferência de material carga de cada um, com base em um extrato retirado do SILOMS, pela seção de Registro.

**Problema:** Apesar o sistema permitir extrair um arquivo csv, o costume é extrair um arquivo pdf, com formatação e distribuição das informações que atendam ao visual humano, mas que por vezes vem com excesso de informação, ou com organização incômoda para ser feito manualmente

**Solução:** Quando chegar o período de conferência, pretendo baixar o arquivo csv, importá-lo em um site, e a partir daí fazer a conferência de maneira rápida e prática, pois deste modo não precisarei ficar andando com algumas folhas de papel na mão, nem ter que ficar procurando o número do patrimônio.
